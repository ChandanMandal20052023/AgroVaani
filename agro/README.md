# Farm To You

Create a premium, high-fidelity landing page UI for an agricultural blockchain traceability platform called AgroVaani.

Core Concept

The landing page should communicate:

“From Farm to You. Every Step Verified.”

The visual identity should combine modern agriculture, trustworthy technology, sustainability, and blockchain transparency. Make it feel like a premium next-generation agri-tech product—not a cryptocurrency website or generic SaaS dashboard.

Color Direction

Use a fresh alternative palette instead of the typical brown/green agricultural palette:

Deep Teal — #073B3A

Ocean Teal — #0F766E

Soft Mint — #BFE8D4

Warm Ivory — #F8F4E8

Sand — #E8DCC4

Coral Orange — #F28C5B

Golden Yellow — #F4C95D

Deep Navy — #102A43

Use ivory and soft mint as the primary background colors, deep teal for typography and major sections, and coral/gold only for important CTAs, verification indicators, and highlights.

Avoid excessive gradients, neon colors, purple-heavy Web3 styling, dark cyberpunk aesthetics, and cryptocurrency imagery.

Important Design Constraint

Do not create a generic dashboard.

This is a marketing landing page, so prioritize:

Storytelling → Product value → Visual trust → Product tracking → Technology → Sustainability → CTA

The first screen should immediately communicate:

“This platform connects real farms and real people through a transparent, verifiable digital supply chain.”

Create the result as a production-quality Figma/Dribbble-level web design, with exceptional hierarchy, spacing, typography, accessibility, responsive behavior, and visual consistency.
